    Bugs fail in two ways

    A bigger model cannot guess a method that was renamed after it was trained. A web search cannot solve a graph algorithm. Mjolnir reads the error and sends each bug down the right road.

    Missing knowledge

    ImportError, AttributeError or an unknown keyword. The code calls an API that changed in 2026.

    Fix: Nano with live Tavily docs

    Missing reasoning

    AssertionError on an edge case. The API is fine; the logic is wrong. Search would only add noise.

    Fix: escalate to Super, then Ultra
